### AI 결과의 한계 안내
AI 결과는 같은 문장이라도 미세하게 다를 수 있습니다. T1~T3은 **대표적인 문장이라 같은 결과가 나와야 정상**이며, 그렇지 않으면 프롬프트(`04` 문서)를 확인합니다. T12처럼 모호한 문장은 특정 정답을 요구하지 않습니다.

## 3. Vercel 배포 절차

### 3-1. 배포 전 점검 (에이전트가 직접 실행)
```bash
# 1) 비밀 키가 Git에 올라가지 않았는지
git status                       # .env.local 이 보이면 안 됨
git ls-files | grep -E "\.env"   # .env.example 만 나와야 함

# 2) 브라우저 코드에 비밀 정보가 없는지
grep -rniE "sk-|service_role|OPENAI_API_KEY|SUPABASE" public/   # 결과 없음이어야 함

# 3) 위험한 DOM 삽입 사용 여부
grep -rn "innerHTML" public/     # 결과 없음이어야 함

# 4) 허용되지 않은 패키지 확인
cat package.json                 # dependencies에 openai, @supabase/supabase-js 만 있어야 함
```
결과를 사용자에게 보고한다. 하나라도 문제가 있으면 배포하지 않는다.

### 3-2. 사용자가 직접 하는 일 (에이전트가 클릭 순서대로 안내)
> 에이전트는 사용자 허락 없이 `git push`, `vercel --prod`를 실행하지 않는다.

1. 프로젝트를 GitHub 저장소에 올린다 (`.env.local`은 올라가면 안 됨)
2. vercel.com 로그인 → **Add New → Project** → GitHub 저장소 선택 → **Import**
3. **Framework Preset**은 `Other`(자동 감지 값 유지), 빌드 설정은 건드리지 않는다
4. **Environment Variables** 섹션에 아래 4개를 **하나씩** 추가한다 (값은 `.env.local`에서 복사)
   - `OPENAI_API_KEY`
   - `OPENAI_MODEL`
   - `SUPABASE_URL`
   - `SUPABASE_SERVICE_ROLE_KEY`
5. **Deploy** 클릭 → 완료되면 `https://프로젝트이름.vercel.app` 주소가 나온다
6. 이 주소를 에이전트에게 알려준다 (키는 알려주지 않는다)

### 3-3. 배포 후 확인
1. 배포 주소 접속 → 5개 카드가 정상 표시된다
2. 테이블 2번의 **T1~T11을 배포 주소에서 다시 실행**한다 (T8, T10은 키를 건드릴 수 없으므로 **로컬에서만** 실행하고 "배포에서는 생략"이라고 보고)
3. 브라우저 개발자도구 **Network 탭**에서 `analyze` 요청을 열어 확인한다
   - Request/Response, Headers 어디에도 `sk-…` 또는 `service_role` 값이 없다
4. Supabase Table Editor에서 배포 주소로 분석한 기록이 쌓였다

### 3-4. 배포 문제 해결 안내표

| 증상 | 흔한 원인 | 확인 방법 |
|---|---|---|
| 화면은 뜨는데 분석이 `SERVER_CONFIG_ERROR` | Vercel 환경변수 누락 | Vercel → Settings → Environment Variables 확인 후 **재배포** (변수 추가 후엔 재배포해야 반영됨) |
| `OPENAI_ERROR` | OpenAI 키 오류 / 결제 미등록 / 모델 이름 오류 | OpenAI 대시보드의 키·결제·사용 한도, `OPENAI_MODEL` 값 확인 |
| 404 `/api/analyze` | `api/analyze.js` 위치 오류 | 프로젝트 **최상위**의 `api/` 폴더에 있는지 확인 |
| 한글이 깨짐 | HTML 인코딩 | `index.html` `<head>`에 `<meta charset="UTF-8">` 확인 |
| 글꼴이 안 바뀜 | Google Fonts 링크 오류 | `index.html`의 `<link>` 확인, 네트워크 차단 여부 확인 |
| 응답이 오래 걸리다 실패 | 함수 시간 제한 | `vercel.json`의 `maxDuration` 확인 |

### 알려진 한계 (보고서에 반드시 포함)
- AI의 감성 판단은 **참고용**이며 항상 정확하지 않다.
- 반어법·비꼬는 말·은어는 오판할 수 있다.
- 입력 문장이 DB에 저장되므로 공개 서비스 시 개인정보 안내가 필요하다.
- OpenAI 사용량에 따라 **비용**이 발생한다.
